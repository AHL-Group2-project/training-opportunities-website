# Frontend

This is the React frontend for the Training Opportunities Website.

## Tech Stack

- React
- TypeScript
- vite
- MaterialUi

## Project Structure

```text
src
├── components
├── pages
├── services
├── App.jsx
└── main.jsx
```
---

## Getting Started
```bash
npm install
npm run dev
```
